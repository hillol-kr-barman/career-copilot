# Career Copilot

An AI-powered career assistant that audits resumes against job descriptions, simulates and scores mock interviews, and screens text for AI-generated content — built with React 19, Express, and Google's Gemini API.

## Features

### 📄 Resume Audit
Paste a job description and a candidate resume, and Gemini generates a structured report split into tabs:

- **JD Review** — critique of the role, with mandatory minimum requirements auto-highlighted
- **Resume Review** — honest read on the candidate's strengths/gaps
- **ATS Score** — an estimated 0–100% match score with rationale
- **JD Scorecard** — the JD's core pillars (skills, leadership, communication, etc.) scored individually
- **Resume Rewrite** — suggested rewrites of specific sections
- **Strengthening** — actionable additions (certifications, key phrases, project details)
- **Change Comparison** — current vs. recommended phrasing, side by side
- **Cover Letter** — a tailored draft linking resume highlights to the JD
- **Interview Preparation** — behavioral questions targeting resume gaps
- **Iteration Tracking** — guidance for tracking multiple resume versions
- **Readiness Analysis** — a summary verdict on overall candidate readiness

Includes an **AI Content Detector** card that scores any pasted/uploaded text for likely AI authorship. This runs entirely offline using a local statistical model (no API key, no external call) that combines six linguistic signals: sentence-length burstiness, vocabulary richness (type-token ratio), AI-hallmark phrasing (e.g. "it's worth noting", "delve into"), transition-word density, average sentence length, and punctuation variety. If you run a local [fast-detect-gpt](https://github.com/baoguangsheng/fast-detect-gpt) server, set `FAST_DETECT_GPT_URL` in `.env` and the app will call that instead.

### 🎤 Interview Prep
- Generates 5–8 tailored interview questions from the JD + resume via Gemini
- A manual scoring ledger scores each question on STAR criteria (Situation, Task/Environment, Action, Result/Technique) and core competencies (Communication Style, Adaptability/Expertise, Analytical Reasoning), auto-averaging both into a STAR rating and a Competency rating per row
- Aggregate metrics (mean score, count of strong answers ≥ 0.75, count of weak answers < 0.5) are computed live from the ledger
- A final **Executive Assessment Report** is generated by Gemini from the scoring data and question context

### 🔧 Manage
A gated settings tab (demo credentials: `qibaitintern` / `qibaitintern`) intended for customizing the default fallback prompts used by the three AI actions above.

> **Note:** this tab is currently a UI mockup — the prompt fields aren't persisted or wired into the API calls. Use the per-card "Override Prompt" file uploads on the Resume/Interview tabs for a working way to swap prompts today.

## How it works

- `server.ts` is a single Express server that:
  - runs Vite in middleware mode during development, and serves the built SPA in production
  - exposes `/api/resume/analyze`, `/api/interview/questions`, and `/api/interview/evaluate`, each of which builds a prompt from your inputs and calls the Gemini API (`@google/genai`)
  - exposes `/api/ai-detect`, which runs entirely locally (see AI Content Detector above)
- The client lets you override the model (`gemini-2.5-flash` / `gemini-2.5-pro` / `gemini-1.5-flash` / `gemini-1.5-pro`) and supply your own API key at runtime; both are stored in `localStorage` and take precedence over the server's `GEMINI_API_KEY`.
- **Document upload caveat:** the file uploader reads real text from `.txt`/`.csv` files. For richer formats (PDF, DOCX, XLSX) it does **not** parse the actual document — it generates a placeholder resume text derived from the filename, purely so the rest of the flow has something to work with. Paste raw text directly, or use `.txt`, if you need the analysis to reflect real content.

## Getting Started

**Prerequisites:** Node.js 18+

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and set your Gemini API key:
   ```bash
   cp .env.example .env
   ```
   ```
   GEMINI_API_KEY="your-gemini-api-key"
   ```
   (You can also skip this and paste a personal API key directly into the app's Settings panel at runtime.)
3. Run the app in development mode:
   ```bash
   npm run dev
   ```
   The app runs at `http://localhost:3000`.

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the dev server (Express + Vite middleware, HMR enabled) |
| `npm run build` | Build the client bundle with Vite and bundle the server with esbuild into `dist/server.cjs` |
| `npm start` | Run the production build (`node dist/server.cjs`) |
| `npm run clean` | Remove the `dist/` directory |
| `npm run lint` | Type-check the project with `tsc --noEmit` |

## Project Structure

```
server.ts                          Express server: API routes + Gemini calls + local AI detector
src/
  App.tsx                          Main app shell: tabs, state, API calls, report rendering
  types.ts                         Shared TypeScript types (ScoreRow, ResumeReportData, etc.)
  components/
    StackingContainer.tsx          Numbered "step card" layout used across both audit flows
    FileUploader.tsx               Drag-and-drop file input with text extraction
    InterviewScoringTable.tsx      Editable STAR/competency scoring ledger with sliders
public/background/                 Optional custom background image (see its own README)
```

## Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, lucide-react icons, Motion (Framer Motion successor)
- **Backend:** Express, Vite (middleware mode in dev, static serving in prod)
- **AI:** Google Gemini via `@google/genai`
- **Tooling:** esbuild (server bundling), tsx (dev server runner), TypeScript
