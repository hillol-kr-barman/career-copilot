# Background Image Directory

Place your custom background photo in this folder. The app is set up to automatically load your background photo if it's named as one of the following:

- `background.jpg`
- `background.png`
- `background.jpeg`
- `background.webp`
- `bg.jpg`
- `bg.png`
- `bg.jpeg`
- `bg.webp`

## How it works
The CSS specifies multiple fallback layers. If you place a file like `background.jpg` here, it will be layered perfectly. If no file is uploaded or found, it falls back to an elegant slate radial gradient seamlessly!
